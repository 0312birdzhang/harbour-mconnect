# 海报与歌词缓存

海报优先读取应用缓存。网络海报位于 `$XDG_CACHE_HOME/harbour-mconnect/.artwork`（默认 `~/.cache/harbour-mconnect/.artwork`），以 URL 哈希作为文件名，扩展名为 `.mca`。文件包含应用标识、完整性摘要和经过掩码的内容，不具有 PNG/JPEG 等文件头；目录内另放置 `.nomedia`。它是防媒体索引的专用封装，并非安全加密。

列表、播放器、迷你播放器使用相同缓存。系统 MPRIS 和 cover 通过仅监听回环地址、带随机会话路径的内存解码端点读取图片，不导出普通图片临时文件。旧网络图片缓存按需转换，成功保存后才移除对应旧文件。本地音乐重新提取内嵌封面时也保存为 `.mca`，保留对既有普通封面的读取兼容。

有效网络海报不会因 HTTP 缓存过期而重新下载；缺失、损坏时才联网。网络海报磁盘缓存上限为 200 MB，按使用时间回收；单张图片限制 16 MB，内存保留最多 20 张 / 32 MB。本地内嵌封面随本地曲库管理，不计入网络缓存额度。

歌词保存在应用 SQLite 的 `lyrics_cache` 表，按平台和歌曲 ID 区分，不向音乐目录导出 `.lrc`。切歌时后台预取，即使没打开歌词页也会保存。已有可解析歌词优先返回，默认不再因 14 天 TTL 到期而先联网；显式刷新策略仍可选择检查 TTL。内嵌/旁挂本地歌词优先于数据库缓存。

平台歌词、逐字歌词、翻译及 LRCLIB 备用结果均可持久化，备用来源使用版本化封装保留来源标签。没有歌词或失败请求不写入空缓存。旧数据库记录保持兼容，写缓存失败不会使已有歌词丢失。

测试：`artwork_cache_test.dart`、`lyrics_cache_test.dart`、`local_music_repository_test.dart`；使用隔离目录和本机 HTTP，不播放音乐。
